# 硬伤 Excel 输出格式

所有核对结果都输出成 Excel，不改源 Word，也不在 Word 里插批注。

## 文件命名

| 场景 | 文件名 |
|---|---|
| 单份文件硬伤 | `<项目>-<文档简称>-硬伤清单_<MM-DD-YYYY>.xlsx`，如 `L2-Step1-MOR-硬伤清单_10-28-2026.xlsx` |
| 多份文件参数核对 | `<项目>-<文档A>-<文档B>-<文档C>-三方核对_<MM-DD-YYYY>.xlsx` |
| 对照终版的批注 | `<项目>-<文档简称>-批注清单.xlsx` |

日期用用户上传文件上的日期，不用当天日期。

## 工作表

### 1. 硬伤表（每份文件一张，表名如 `MOR 硬伤`、`PVP 硬伤`）

| 列 | 宽 | 写法 |
|---|---|---|
| 序号 | 6 | 1 起连续 |
| 类别 | 16 | 固定用：`与 PVP/参数表不一致`、`内部数值/逻辑`、`中英翻译`、`笔误/格式`。只审一份文件时可省略本列 |
| 严重程度 | 9 | `高` / `中` / `低`，定义见下 |
| 位置 | 34 | 节号、表号、步骤号、页眉页脚。一处多发时列全，如 “3.5.5、3.8.5 … 3.43.5” |
| 内容（Word 中搜索） | 36 | 原文短句，原样复制，能在 Word 里直接搜到。规则见下 |
| 问题与改法 | 90 | 先写错在哪里，带上各方数字；再写改成什么。一行一件事 |

行的排序：先按类别（不一致 → 内部数值/逻辑 → 翻译 → 笔误），类别内按严重程度高 → 低。

### 2. 三方参数核对表（`三方参数核对`）

| 列 | 宽 |
|---|---|
| 序号 | 6 |
| 参数 | 22 |
| 参数表 <日期>（行号 / 值） | 38 |
| PVP <日期>（位置 / 写法） | 40 |
| MOR <日期>（操作号 / 写法） | 46 |
| 判断 | 46 |
| 建议改哪里 | 46 |

“判断”写为什么算问题（超出 NOR、超出 PAR、单位差 1000 倍、执行会按哪一个）。“建议改哪里”写改哪份文件、哪几个步骤、改成什么数。

### 3. 对应关系表（`参数表-MOR 对应关系`）

| 序号 | 参数表行 | 我判断的 MOR 操作号 | 说明 | 把握（高/中/低） |

只在参数表行名与 MOR 操作号对不准时出这张表。把握为“低”的行同时写进“需要你确认”。

### 4. 需要你确认（`需要你确认`）

| 序号 | 问题 |

每个问题是一句可以直接回答的话，给出选项，如 “按 10.0 V / 8.73 kg/kg，还是按 MOR 的 10.64 V / 9.29 kg/kg？”。

### 5. 附加表（按需）

`PVP 硬伤`、`参数表内部问题`、`MOR 内部问题` 用硬伤表的列。

## 严重程度

- **高**：会执行错或无法执行（中文为准时中英数字不同、占位符、CPP 超 NOR/PAR、单位错、缺 IPC、文件号/项目号引错、两套数并存）。
- **中**：不一致但不直接越界，或需要用户决定（MOR 比 NOR 窄、引用号错位、标题与内容不符、翻译改变意思）。
- **低**：笔误、格式、缩写表、页码。

## 搜索句规则

1. 原样复制，大小写、全半角、空格都不改。
2. 只取同一段落或同一表格单元格的一行；跨段落、跨单元格在 Word 里搜不到。
3. 避开不间断空格（`\xa0`）。原文 “低限:\xa022\xa0oC” 这类，改取附近没有空格的词，如 `XoC`、`32 oC`、节标题。
4. 尽量短且独特（10–40 字）。命中多处时，在“位置”写明是哪一处。
5. 页眉页脚里的字也可以用，位置写“页眉/页脚，第 X 页起”。
6. 交付前用脚本逐条校验（`scripts/write_review_xlsx.py` 会自动做）；校验不过的不要交付。

## “问题与改法”写法

- 先给事实再给结论：“MOR 写 X，PVP 和参数表是 Y，……按 MOR 执行会 Z。”
- 数字带单位和来源；换算写出过程，如 “8.15 kg/kg × 48 kg = 391.20 kg”。
- 客户批注写人名和日期，如 “Johan（礼来）10/25、10/27 未关闭”。
- 同类错误合并成一行，列出所有位置，不要拆成几十行。
- 不确定的写“请确认”，并把它放进“需要你确认”表。
- 不写“建议考虑”“可能需要”这类空话。

## 生成

写一个 JSON spec，运行 `python scripts/write_review_xlsx.py spec.json`。

- 每张表给 `name`、`columns`（不含序号）、`rows`；要校验搜索句时给 `source`（.docx 或 .xlsx，路径相对 spec）。
- 序号、列宽、排序（有类别和严重程度时）、样式都由脚本处理。
- `--check` 只校验不写文件；`--example` 打印样例。
- 校验不过（找不到、跨段、含 `\xa0`、严重程度不是高/中/低）时退出码非 0，并且不写文件。

`scripts/mor_auto_checks.py --xlsx` 产出的“自动检查候选（待人工筛）”只是候选，不是交付物。

## 样式

- 表头：填充 `1B4F72`，白色粗体 Calibri 11，自动换行，垂直居中。
- 正文：Calibri 11，自动换行，顶端对齐，细边框 `D0D7DE`，偶数行底色 `F7F9FB`。
- 冻结首行，首行加筛选，横向打印并适应页宽。
